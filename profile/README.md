# webgl-games

Open-source games and 3D experiences that run in the browser.

| Project | What it is |
|---|---|
| [arcade-3d](https://github.com/webgl-games/arcade-3d) | Five browser 3D games in one: open world, team deathmatch, battle royale, destruction sandbox and a rocket mission, with online multiplayer. **[▶ Play in your browser](https://webgl-games.github.io/arcade-3d/)** |
| [flight-sim](https://github.com/webgl-games/flight-sim) | A WebGL flight simulator: three aircraft, ring and landing challenges, leaderboards |
| [opencity](https://github.com/webgl-games/opencity) | Open-world driving in Godot 4: walk, drive and fly a helicopter through a procedural city |
| [live-3d-cricket](https://github.com/webgl-games/live-3d-cricket) | Live cricket in 3D: ball-by-ball commentary turned into stadium action |
